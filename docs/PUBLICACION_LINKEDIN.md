## Sección Proyectos

**Nombre:** AppointmentSaaS: Gestión Inteligente y Analítica para Negocios de Servicios

**Descripción:**

AppointmentSaaS es una plataforma SaaS B2B diseñada para micro-PYMES dominicanas del sector servicios. Permite a negocios como barberías, salones de belleza y spas administrar citas, configurar horarios, reducir conflictos de agenda y convertir los datos de reservas en indicadores para apoyar decisiones operativas.

**Tecnologías:** HTML5, CSS3, JavaScript, Supabase Auth, PostgreSQL, Row Level Security, Supabase Edge Functions, Resend y Vercel.

## Publicación

Durante Proyecto Integrador II participé en el desarrollo de **AppointmentSaaS**, una solución orientada a digitalizar la gestión de citas de micro-PYMES dominicanas del sector servicios.

El proyecto responde a problemas frecuentes como la coordinación mediante libretas o mensajes, los conflictos de horarios, las inasistencias y la falta de datos para conocer horas pico o servicios rentables.

La solución incluye un portal para clientes, un panel administrativo y una experiencia limitada para empleados. Implementa registro e inicio de sesión, agenda compartida, reglas de disponibilidad, horarios semanales, cierres especiales, prevención de solapamientos, analítica, bitácora y correos de confirmación.

**Tecnologías utilizadas:** HTML5, CSS3, JavaScript, Supabase Auth, PostgreSQL, Row Level Security, Supabase Edge Functions, Resend y Vercel.
