- Interfaz completa de cliente, administrador y empleado.

- Esquema PostgreSQL.
- Datos iniciales.

## Requiere acciones de la estudiante

- Crear el proyecto real de Supabase.
- Ejecutar el SQL.
- Crear las credenciales demo con el script.
- Crear cuenta Resend y verificar dominio.
- Configurar secretos y desplegar Edge Function.
- Agregar variables a Vercel.
- Publicar el repositorio.
- Probar la URL pública.
- Completar enlaces y grupo en documentos.
- Grabar video y publicar en LinkedIn.

## Criterio para afirmar que cumple al 100 %

No se debe declarar completado hasta que:

1. La URL pública indique “Supabase PostgreSQL conectado”.
2. Los tres usuarios inicien sesión.
3. Los datos sean compartidos entre navegadores.
4. El correo llegue realmente.
5. Los casos críticos del plan de pruebas estén aprobados.
6. El documento técnico tenga los enlaces finales.
7. LinkedIn, Teams y Blackboard estén completados.
